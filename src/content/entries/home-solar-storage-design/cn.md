# 概述

这是我的 DIY 项目：一个围绕低功率柔性太阳能板打造的储能系统。目前的形态是为 LED 照明离网供电；未来拓展、或者需要给家用高负载设备供电时，太阳能板会升级为固定的屋顶太阳能板。

这个项目里最有意思的工程问题是一条**电压匹配约束**：电池只有在太阳能阵列的工作电压足够高于它时才能被充电，而这一条规则几乎决定了后面的一切：板子组合、电池电压与控制器选型。整个设计都是从这条规则推出来的。

# 需求

| 需求      | 指标                                                        |
| --------- | ----------------------------------------------------------- |
| 夜间照明  | LED，50W × 8h = 每晚 400Wh                                  |
| 储能      | 2 × 12V 100Ah LiFePO₄ 串联 = 24V（~2.5kWh，可扩容）         |
| 太阳能    | 2 × 300W 便携半柔性板（低功率阶段；未来高负载时升级屋顶板） |
| 230V 备用 | 24V × 100A ≈ 2400W 理论输出（短时能力，见 §04）             |
| 采购策略  | 太阳能板+电池本地买；其他部件跨国采购                       |

# 设计过程

## 01 调研：电压匹配约束

核心规则来自 MPPT 充电控制器：只有当太阳能阵列电压高于**电池电压 +5V** 时才会启动充电，运行中也需要大约 +1V 的余量。选定的 300W 半柔性露营板工作电压只有 20Vmp，单块不足以充 24V 电池；两块串联得到 40Vmp / 50Voc，无论配 12V 还是 24V 电池都远超启动阈值，即使在 -20°C 低温下也远低于控制器 100V 上限。

MPPT 与电池之间的连接采用 16mm² 线缆，受 MPPT 端子最大支持 16mm² 的限制；理想情况下应采用 25mm² 线缆预留足够的安全余量。

市场调研方面：荷兰市场 12V 电池包是房车/船用主流，储能侧采用 2 × 12V 100Ah；线径规则、保险丝位置与充电参数随后对照 Victron 手册、《Wiring Unlimited》布线规范和 DIY 社区案例逐项复核。

## 02 系统架构

![系统架构图](./solar-concept-design.png)

控制器是一台六端口 MPPT（PV / BAT / LOAD），这意味着**母线内置在 MPPT 里面**：太阳能接 PV 端口、电池经 2P 直流空开接 BAT 端口、负载直接挂在 LOAD 端口，不需要外部母线。任一时刻电池电流 = 负载电流 − 太阳能电流；电池是唯一的双向器件，多余功率自动吸收、缺口自动补足。

两节 12V 电池**串联**成 24V：这样逆变器支路只需走 100A 级别的电流（24V × 100A = 2400W 理论输出）；若并联 12V 则需要 200A，超出 MPPT 的支持范围。电池内置 BMS，各自负责充放电保护。

## 03 关键决策

| 项目     | 决策                                                 | 理由                                                                                  |
| -------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 电池     | 2× 12V 100Ah LiFePO₄ 串联 = 24V（各 100A BMS，内置） | 串联后逆变器支路仅 100A 级电流（24V×100A=2400W）；同型号同批；串联前确认 BMS 支持串联 |
| 太阳能板 | 2 × 300W 半柔性串联                                  | 便携优先；20V 板必须串联；屋顶板是未来升级路线                                        |
| 控制器   | 六端口 MPPT（PV / BAT / LOAD）                       | 负载输出内置，母线就在控制器里面；BAT 端子最大 16mm²                                  |
| 逆变器   | 纯正弦逆变器（24V 输入）                             | 2400W 理论值，短时使用                                                                |
| 保护     | 直流专用无极性空开 + 隔离开关                        | 空开额定 ≤ 线缆载流；必须直流专用，交流空开灭不了直流电弧                             |

## 04 效率计算：230V 链路

每一级转换都会吃掉一部分能量。本功率等级下的典型效率：

| 环节                | 典型效率 |
| ------------------- | -------- |
| MPPT DC-DC 转换     | 92~95%   |
| LiFePO₄ 充 + 放往返 | ~95%     |
| 纯正弦逆变器 DC→AC  | 88~93%   |

整条链路相乘（板 → 电池 → 逆变 → 230V）：

**0.94 × 0.95 × 0.90 ≈ 80%**

实际预计 **77~84% 的端到端效率**（典型 ~80%）。作为对比，LED 支路完全跳过逆变（经 MPPT + 电池约 90%），这正是照明走直流直供、230V 只作备用的原因：每经过一次逆变链路，大约五分之一的能量留在半路。

## 05 保护与安全

- PV 侧：20A 2P 无极性直流空开，兼维护隔离开关；MPPT-电池支路经 2P 直流空开（兼电池隔离）。所有空开/隔离开关必须直流专用且无极性，交流空开灭不了直流电弧。
- LOAD 支路：LED 直接挂 LOAD 端口（经光控/时控开关）；逆变器支路经直流隔离开关做日常通断，顺带消除待机耗电。
- 接线规范：MPPT 是常见的绿色螺丝压片式端子，配合冷压管端子使用（禁止上锡，焊锡蠕变致松动发热）；M8 螺柱配闭口铜鼻子（禁止开口款）；液压钳压接；红正黑负全程一致。
- 电池串联：同型号同批，确认 BMS 支持串联，串联前各自充满。
- 通电顺序：极性核对后再上电；先接电池、再接光伏；充电参数按 LiFePO₄ 24V 规格设置。

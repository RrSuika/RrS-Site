# RC 无源滤波器：简单到只用两个元件，但到处都能看到它

看完这篇你会知道三件事。一个电阻加一个电容，为什么能把快信号和慢信号分开。两种接法各用在哪。两个元件又怎么取值。

我做的第一个滤波电路就是一个电阻加一个电容。当时觉得太简单了，不可能有用。可这一对元件到处都在：测量电压的芯片前面、脏电源后面、会弹跳的按键上。

## 核心原理：电容的阻抗随频率变化

电阻拦电流，信号快慢它都一样拦。电容不一样：信号越快，它越不当回事。这种看速度行事的拦阻，叫阻抗。

把电容摆在电阻旁边，两者对快慢信号的分法就不一样。这就是滤波。

- **慢信号（低频）**：电容像线上一处断口。
- **快信号（高频）**：电容像一段普通导线。
- **截止频率**：两者一样难过去的那个频率。比它低的能出来，比它高的被压低。写作 fc：**fc = 1/(2πRC)**。

R 单位欧姆，C 单位法拉，算出来的 fc 单位赫兹。任何一个取大一点，截止频率就往下走，不必手算。

## RC 低通滤波器

### 电路长什么样

```
Vin ── R ──┬── Vout
            │
            C
            │
           GND
```

电阻串在信号通路上。电容从旁边搭到地，地就是所有电压都拿来做参考的那条 0V 线。慢信号顺着电阻走到输出，快信号改走电容，被丢到地上。

### 它对快信号和慢信号做什么

- 截止频率以下的信号，基本原样出来。
- 截止频率以上的会变小：频率高十倍，出来就小十倍。
- 一直不变的稳定电压，原样通过。

### 我实际在哪里用它

- **放在测量电压的芯片前面。** 这种芯片叫 ADC，每秒读很多次。比它读得还快的信号，读出来就是错的。低通先把它削掉。
- **放在开关电源后面**，它会在输出上留一层很快的杂波。
- **接在会弹跳的按键上。** 10kΩ 配 100nF 能把跳动抹平，但只抹圆边沿。所以我还是会在软件里再确认一次。
- **接在快速开关的引脚上。** 这叫 PWM。低通交给你平均值，也就是一个便宜的可调电压。
- **用在音箱分频上**，把低音送进大喇叭。

### 要注意的地方

- 接在输出后面的东西要比 R 更难通过，不然截止频率会被挪走。
- 一级 RC 很温和。想切得更陡，就串两级，或者改用有源滤波。
- 信号通路里的电容要挑对，有些便宜陶瓷电容会让信号失真。

## RC 高通滤波器

### 电路长什么样

```
Vin ── C ──┬── Vout
            │
            R
            │
           GND
```

还是那两个元件，位置对调。电容串在信号通路上，电阻搭到地。快信号轻松穿过电容，慢信号过不去，剩下一点也被拉到 0V。

### 它对快信号和慢信号做什么

- 截止频率以上的信号，基本原样出来。
- 截止频率以下的会变小，速度和前面一样。
- 截止频率用的是同一个公式：**fc = 1/(2πRC)**。

### 我实际在哪里用它

- **把传感器信号里固定的那部分剥掉。** 很多传感器输出一个稳定电压，上面叠着一点抖动。信息就在抖动里，高通只留抖动。
- **放在两级音频之间。** 两级各停在一个不同的稳定电压上。电容让声音过去，稳定电压过不去。
- **用在人体移动感应器里。** 人走过，红外变化快；房间慢慢变热，红外变化慢，高通只留下人。
- **用在心电信号上。** 电极自带一个很大的稳定电压，先去掉它。这样心跳那点小信号才放大得起来。
- **用在音箱分频上**，把高音送进小喇叭。

### 要注意的地方

- 截止频率要设得比你在意的最慢信号低很多。不然会把它一起削掉。
- 给滤波器送信号的那一级也有电阻，它会加到 R 上。所以 R 得足够大才说了算。
- 电容别取得比需要的大，大电容上电后要更久才稳。

## RC 带通滤波器

前面放高通，后面放低通，就只剩中间。太慢的被前一级挡住，太快的被后一级挡住。

有一个坑：后一级会把前一级往下拽，两个截止频率都跟着跑。在意数值的话，中间加一级缓冲。缓冲就是照抄电压、但不从前面取电流的那一级。图里没有画出它。

```
Vin ── C1 ──┬── R1 ──┬── Vout
             │        │
             R2       C2
             │        │
            GND      GND
```

你要的是一段频率、别的都不要时，就用它。比如调音器，或者从一堆信号里挑出某一个。

## 别忘了时域：时间常数 τ

前面讲的都是频率。同样这两个元件还决定输出电压能变多快。你按下开关那一刻，起作用的就是它。

让电容通过电阻充电，电压就往上爬，一开始快，后面越来越慢。这一趟由 **τ = RC** 定下来，R 单位欧姆，C 单位法拉，τ 单位秒。过了 1 个 τ，大概走了三分之二；过了 5 个，就基本到位。

所以电阻或电容取大，电路就更慢。凡是要等一会儿的电路，比如上电延时、去抖计时，都是这么做出来的。

## 有源滤波器：后续要深入的方向

只用电阻和电容的滤波器叫无源滤波器。它有三个短板：输出弱、只能变小、切得不够陡。

在 RC 后面加一颗放大芯片，三件事一起解决。输出变强了，信号能放大了，还能把一部分输出送回去改变衰减形状。这就是有源滤波器。你会碰到的名字有 **Sallen-Key**（最常见）和**多路反馈**（切得更陡）。还有**开关电容滤波器**，截止频率由时钟定，容易做进芯片。

不过先把无源这版学扎实。很多时候一个简单的 RC 就够了。
